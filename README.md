# Genetic Chaos
Python script generates the number of possible combinations of human genomes ( $4^{3,200,000}$ , or $10^{1,926,592}$ )
## PT - BR
O genoma humano tem um total de 3.2 BILHÕES de caracteres, que variam entre as letras A, C, T e G. Essas letras são a base para qualquer ser vivo, de uma formiga a uma baleia, e até mesmo eu e você!   Porém, de ser humano para ser humano, somente 0.1% varia, o que significa que apenas 3.2 M. de letras variam de pessoa para pessoa. Isso quer dizer que existem $4^{3.200.000}$ (ou $10^{1.926.592}$) variantes do código genético humano. Esse número se traduz para 1 com 1.926.592 zeros atrás. Exemplificando, se cada zero ocupasse 0.5 cm, escrever esse número secaria 5 canetas e exigiria um espaço de 9,63 KILÓMETROS para escrever. E o número $10^{1926592}$ é tão massivo que é impossível mostrá-lo com qualquer outra comparação, tornando cada pessoa única e insubstituível.   
## EN -US
The human genome consists of a total of 3.2 BILLION characters, represented by the letters A, C, T, and G. These letters form the foundation for every living being—from an ant to a whale, and even you and me! However, between one human being and another, only 0.1% varies, which means that just 3.2 million of these letters differ from person to person. This implies that there are $4^{3,200,000}$ (or $10^{1,926,592}$) possible variants of the human genetic code. This number translates to a 1 followed by 1,926,592 zeros. Exemplifying, if each zero were 0.5 cm wide, writing out this number would exhaust 5 pens and require a space 9.63 KILOMETERS long. The number $10^{1,926,592}$ is so massive that it defies any other form of comparison, rendering every single person unique and irreplaceable.
